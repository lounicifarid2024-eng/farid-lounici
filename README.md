### Le Binôme Intelligent

Principe de gouvernance : **« L’IA propose ; l’humain décide. »**

Ce dépôt contient une preuve technique minimale de ce principe :
- un manifeste de profil structuré (`binome_profile.json`) ;
- un validateur Python strict (`src/validate_binome_profile.py`) ;
- des tests de gouvernance (`tests/`) ;
- une politique de sécurité (`SECURITY.md`) ;
- une CI GitHub Actions à permissions minimales.

Le validateur refuse notamment :
- la suppression de l’autorité humaine finale ;
- la désactivation du mode *deny-by-default* ;
- l’absence de validation humaine sur les actions sensibles ;
- la transformation du profil en fausse certification externe.

### Portée de la validation

Cette validation est **interne, technique et auto-documentée**. Elle ne constitue ni un diplôme, ni une certification officielle, ni une preuve scientifique de compétence ou de performance.

Référence de travail au 9 septembre 2026 :
- indice comparatif interne de capacité appliquée : **79/100** ;
- indice interne de preuve marché/industrialisation : **65–70/100**.

Ces indices servent uniquement au pilotage du développement professionnel. Ils doivent être remplacés ou complétés progressivement par des preuves externes : tests reproductibles, projets techniques, clients mesurés, audits et certifications reconnues.
