## Une méthode vérifiable

1. Cadrer le métier et les données réellement autorisées.
2. Séparer **faits, hypothèses et informations manquantes**.
3. Comparer l'automatisation par IA avec une procédure plus simple.
4. Tester avec des données fictives puis, avec autorisation, dans un environnement réel.
5. Documenter limites, erreurs, coûts et escalade vers une personne.
