# Contribuer

Le dépôt est actuellement un portfolio avec démonstrateurs, pas une plateforme de production.

## Proposer une amélioration

1. Ouvrir une issue décrivant un problème reproductible, sans données personnelles ni secrets.
2. Proposer une modification limitée et documenter ses impacts.
3. Ajouter ou actualiser les tests utiles.
4. Soumettre une pull request en précisant le statut du code : exemple, prototype ou validé.

## Règles

- Ne jamais déposer de clé API, mot de passe, document client ou conversation privée.
- Employer des entreprises et données fictives dans les démonstrations.
- Indiquer les dépendances et les limites des automatisations.
- Éviter les statistiques de résultats, témoignages ou certifications inventés.
- Aucun déploiement ou paiement automatisé sans autorisation du responsable.

**Droits :** l'absence de licence open source explicite signifie que la réutilisation du code n'est pas automatiquement autorisée. Ne pas proposer de contribution externe substantielle sans clarifier d'abord les droits et l'attribution.
